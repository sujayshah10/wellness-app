# Wellness App v0.5 Beta Testing Plan

## 🎯 Beta Goals

Test the complete v0.5 milestone with real users to validate:
- "A new user can set up their wellness plan in under five minutes"
- "Use it daily without confusion"
- "See meaningful weekly progress"

## 👥 Participant Selection

### Target Participants: 5-10 people

**Diversity Criteria:**
- **Fitness Levels:** Beginner (2-3), Intermediate (2-3), Advanced (1-2)
- **Tech Comfort:** Low (2), Medium (3-4), High (2-3)
- **Age Groups:** 20-30 (3), 30-40 (3), 40+ (2-3)
- **Goals:** Weight loss (3), Muscle gain (2), Maintenance (2-3)

**Recruitment Approach:**
- Personal network (friends, family, colleagues)
- Fitness/health communities
- Social media groups

## 📅 Testing Timeline

**Duration:** 7 days per participant

**Schedule:**
- **Day 0:** Onboarding and initial setup
- **Days 1-7:** Daily usage
- **Day 7:** Final feedback collection

**Rollout:** Staggered - 2-3 users per day to manage feedback volume

## 📋 Testing Protocol

### Pre-Test Setup
1. **Provide PWA link** via GitHub Pages
2. **Ensure device compatibility** (iOS/Android web browser)
3. **Brief orientation** (5 minutes)
   - Explain this is a beta test
   - No instructions on how to use - let them discover
   - Encourage honest feedback

### Daily Check-ins (Simple)
**Daily Message (evening):**
```
Hey! How was the app today? Any issues or thoughts?
```

**Only collect if they respond:**
- What worked well
- What was confusing
- Any bugs encountered

### Focus Areas

**Day 0 (Onboarding):**
- Time to complete setup
- Understanding of questions
- Clarity of target calculation
- Transition to main app

**Days 1-7 (Daily Usage):**
- Meal logging friction
- Workout tracking ease
- Progress view clarity
- Completion checklist usage
- Any points of confusion

**Day 7 (Summary):**
- Overall satisfaction
- Most/least used features
- Missing features
- Would they continue using

## 📊 Feedback Collection

### Three Core Questions (Per Your Priority)

**1. Where did you get stuck?**
- Specific UI elements
- Confusing terminology
- Navigation issues
- Technical problems

**2. What did you use every day?**
- Home page
- Completion checklist
- Progress page
- Nutrition tracking
- Workout tracking
- Menu/settings

**3. What did you expect but couldn't find?**
- Features they assumed would exist
- Information they wanted to see
- Actions they wanted to perform

### Collection Methods

**Daily (informal):**
- WhatsApp/Telegram message
- Email response
- Voice message (optional)

**End of Week (structured):**
- 5-minute Google Form
- Optional 15-minute interview
- Screenshots of their progress view

### Success Metrics

**Quantitative:**
- Setup completion rate: Target >80%
- Daily active usage: Target >60%
- Daily task completion: Target >70%
- 7-day retention: Target >50%

**Qualitative:**
- Setup time <5 minutes
- "No confusion" in daily usage
- "Meaningful progress" visible
- Would recommend to others

## 🐛 Issue Tracking

### Severity Levels

**Critical (Blocker):**
- App crashes
- Data loss
- Cannot complete basic tasks

**High (Major):**
- Confusing UI that prevents usage
- Missing essential feature
- Performance issues

**Medium (Minor):**
- Unclear labels
- Minor navigation friction
- Visual bugs

**Low (Cosmetic):**
- Spelling errors
- Minor styling issues
- Nice-to-have improvements

### Bug Report Format

```
Description: What happened
Steps to reproduce: How to trigger it
Expected behavior: What should happen
Actual behavior: What actually happened
Device/Browser: Technical details
Screenshots: If applicable
```
